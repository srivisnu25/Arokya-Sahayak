Firebase Configuration Required

To view your streaks, you need to update your Firebase security rules to allow read access to your data.

Firebase Security Rules Setup

The "Missing or insufficient permissions" error means your Firebase security rules need to be updated to allow read access.

Step 1: Open Firebase Console

Go to the Firebase Console, select your project, then go to Firestore Database > Rules.

Step 2: Update Your Rules

Replace your current rules with these:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Allow users to read and write their own streaks
    match /streaks/{streakId} {
      allow read: if request.auth != null && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null && request.auth.uid == request.resource.data.userId;
    }
    
    // Your existing rules for other collections
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == userId;
    }
  }
}

Step 3: Publish Rules

Click "Publish" to save your new rules. They will take effect immediately.
